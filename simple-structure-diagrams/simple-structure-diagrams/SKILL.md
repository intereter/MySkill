# 简洁模型与代码结构图

用户偏好：讲解论文模型结构或代码结构时，主动配图。默认使用 `assets/style-reference.png` 的论文插图风格；先查看参考图，再设计布局。用户明确指定其他风格或只要文字时，遵循当次要求。

## 核对结构与层级

- 从论文方法、原图、公式或实际代码核对模块和连接，不根据名称猜测。
- 论文图表现输入输出、主干、关键分支和残差。代码图按问题选择模块依赖、运行时调用或数据流，并在图注说明箭头含义；不要把调用关系强行画成神经网络。
- 若仓库存在 `.codegraph/`，遵循适用 AGENTS.md 的 CodeGraph 优先要求；否则正常定位和阅读实现。
- 区分论文示意、发布配置和优化实现。例如 3:1 设计不保证末尾也是完整四层一组，压缩潜在表示也不保证所有后端采用相同缓存格式。
- 一图只讲一个主要层级。复杂模型拆成整体图和局部模块图，不把公式推导、所有函数和配置参数塞进同一张图。

## 视觉约定

白色画布、浅灰分组框、黑色细线、柔和浅色模块框。避免深色仪表盘、渐变、装饰图标和卡片式长段文字。

| 类型 | 建议填色 |
|---|---|
| 分组／block 边界 | `#f3f3f4` |
| Norm／门控／辅助操作 | `#f4f4ce` |
| 线性或循环核心模块 | `#fff1dc` |
| 全局注意力或第二类核心模块 | `#e9baba` |
| MoE／处理组件 | `#ccebf4` |
| 投影／输入输出适配 | `#d7ebd7` |
| 潜在表示／缓存 | `#e5e3ef` |

- 神经网络默认从下向上，与参考图一致；代码结构按流程选择从左到右或从上到下。整图保持一致，图注说明阅读方向。
- 主干居中；分支并排；连接用直线或直角折线。标签置于线的一侧，禁止线穿过文字。
- 框内用短名，如 `Norm`、`Router`、`Parse`。缩写和复杂逻辑放在图下以中文解释。中文标签需使用支持中文字形的字体。
- 残差画成绕过完整子层的旁路，在圆圈 `+` 汇合；逐元素乘法用圆圈 `×`。不要把拼接误画成相加。
- 重复 block 用 `N×`，图注区分独立参数堆叠与共享权重循环。
- 标签太长时先缩短、换行或扩宽模块，不靠不断缩小字体解决。保持框、字、箭头和边界之间的空隙。
- 同构分支或辅助操作可以合并，但在图注交代省略内容；不能省略改变机制或结论的关键路径。

## 生成与嵌入

优先以代码绘制 SVG 矢量图，并生成 2× PNG 供 Markdown 稳定显示。Mermaid 可用作草稿，最终默认嵌入实际图片；用户要求 Mermaid 时除外。此类结构图使用确定性的形状和文字，不需要生成式图片工具。

可复用渲染器：

```text
python <skill_dir>/scripts/render_diagram.py <scene.json> --output-dir <assets_dir> --name <figure-stem>
```

场景模板为 `assets/example-block.json`。渲染器需要 Pillow；系统 Python 缺少时，优先通过工作区依赖工具寻找包含 Pillow 的运行时，不要写死本次任务的运行时路径。字体默认寻找 Times／DejaVu Serif；中文场景用 `--font` 指定支持中文的字体。

JSON 画布包含 `width`、`height`、`title` 和按顺序绘制的 `shapes`：

- `box`：x/y/w/h/label/fill，可选 size/r；fill 可使用十六进制色值。
- `text`：x/y/label，可选 size/bold。
- `line`：points，可选 arrow/dash。
- `circle`：x/y，可选 label（默认 +）。

坐标原点在左上角，文字按中心对齐。通常先画分组底色和连线，再画模块和文字。模板仅作起点，按真实结构重排坐标，不照搬模块或连接。SVG/PNG 使用相同场景，但因字体渲染可能有少量差异，最终检查实际嵌入的 PNG。

## 检查与交付

1. 对照来源核对主干、分支、归一化次序、门控位置、残差起止和重复次数；代码图核对调用方向与跨模块连接。
2. 打开生成图片做视觉检查，修正截断、重叠、文字压线、孤立连接、错误箭头和误导分组，再查看修正结果。
3. 图下简述阅读方向、模块作用和简化项，公式和实现细节放在后面的文字中。
4. 修改已有 Markdown 时，将图片放在文档邻近的独立目录，如 `assets/<article-stem>/`；以相对路径嵌入 PNG，保留同名 SVG。不要依赖临时目录或在线图片才能阅读。
5. 同步用户指定位置的文档、素材与任务输出副本，检查图片引用实际存在。遵循当前任务对输出目录的约束。

交付图与讲解的一体化结果，而非只有建议或图源。最终简述更新内容，链接文档，并可预览一张代表图。
